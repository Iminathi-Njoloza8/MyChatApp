## Features
### Message ID
This is where the random message ID is created.
### Recipient Cellphone Number
This is where the recipients number will be captured and checked if its the correct length.
### Message Length
This is where the message will be inputed and checked if it fits the length range.
### Message Hash
This is what the user will see as a preview of the message at it is showing the first and last words of the message in capital letters.
### Message Details
This part will show the Message ID, Message Hash, Recipient's number, and the message.
### Message Count
This part is where the user will be able to see the amount of messages sent.
### JSON
JSON is where the messages will be stored if the user decides to store the message instead of sending or disregarding the message.
### Sent Message
This part shows what the user will see if they decise to send the message, disregard the message, store the message, or input an invalid number option.
